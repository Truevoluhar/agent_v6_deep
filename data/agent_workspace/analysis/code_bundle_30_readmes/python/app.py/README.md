# app.py

- **Source file:** `/uploads/code_bundle_30/python/app.py`
- **Language:** Python
- **Purpose:** Provides a greeting helper and demonstrates it when run as a script.
- **Key functions/classes:** `greet(name: str) -> str` formats a greeting string.
- **Inputs:** `greet` accepts a name string; the script entry point calls it with `world`.
- **Outputs:** Returns `Hello, <name>!`; when executed directly, prints `Hello, world!`.
- **Notable implementation details:** Uses type hints and the `if __name__ == '__main__'` guard to separate importable function behavior from script execution.
