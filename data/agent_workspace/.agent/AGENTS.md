# Workspace Memory

This workspace is shared by the agent runtime and the workspace API.

Conventions:
- Put uploaded user inputs in `/workspace/uploads/`.
- Put generated analyses in `/workspace/analysis/`.
- Put editable diagrams in `/workspace/diagrams/`.
- Put project checkouts or generated code in `/workspace/projects/`.
- Put final deliverables in `/workspace/exports/`.

When a task creates meaningful artifacts, leave them in the workspace with descriptive filenames.
